# Practice Timer

A focused, dependency-free interval timer for interpreting practice.

## Features

- Presets for consecutive interpreting, listening retelling, and sight interpreting
- Structured task mode with persistent requirements, named phases, automatic transitions, and an actual-time report
- Configurable stage duration, break, and number of rounds
- Automatic phase transitions with optional audio cues
- Fullscreen mode and keyboard shortcuts
- Responsive layout and local preference storage

## Keyboard shortcuts

- `Space`: start or pause
- `N`: next stage
- `R`: reset

## Run locally

Open `index.html` directly, or serve the directory with any static HTTP server.

## Deployment

The app is plain HTML, CSS, and JavaScript and can be published directly with GitHub Pages from the repository root.
